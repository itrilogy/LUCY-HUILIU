## 1. 软件用途

本软件用于在本机或局域网内，对大规模 SVG 矢量插画与图标进行浏览、语义检索、分类筛选、预览编辑（去背 / 换色 / 选块编辑）以及 SVG / PNG 导出。系统可在无外网条件下完成检索与导出；可选配视觉大模型对新素材做语义标注。面向设计、开发、教学与内容制作场景。

## 2. 主要功能

1. **素材浏览与布局**：网格展示全部或分类素材；可调列数（2–10）与每页行数；支持虚拟列表与惰性加载。  
2. **智能检索**：按标题、描述、分类、清洗后的标签进行前缀与模糊检索；多词 AND 组合；中文分类名隐式命中。  
3. **预览编辑**：棋盘格显示透明区域；点选取样到背景色 / 主配色；整图按色清除、整图换色；擦除选块、填充选块；去掉铺满画板的矩形框；撤销 / 还原。  
4. **导出**：下载当前预览的 SVG 或透明 PNG，无需先保存；有未保存修改时文件名附加 `-edited`。  
5. **个性化**：全局主色、深色模式、网格密度。  
6. **资产管理**：批量导入重命名；增量任务清单；AI 视觉标注与缓存续传；标签清洗与精简检索目录。  
7. **权限与写回**：普通用户仅浏览与下载；管理员经服务器校验口令后，可将当前预览写回本地素材库。  

## 3. 技术特点

- 无前端框架，HTML / CSS / 原生 JavaScript，便于离线部署与软著鉴别。  
- 首屏加载精简目录 `catalog.json`，避免一次拉取完整元数据。  
- 网格虚拟化与大体积 SVG 位图预览，适应一万七千级素材规模。  
- SVG 编辑采用可叠加动作栈，下载序列化当前预览 DOM，保证所见即所得。  
- 管理口令仅存在于服务器侧 `.env`（`VS_ADMIN_PIN`），经 HTTP 接口校验后以 HttpOnly Cookie 维持会话；前端不内嵌口令。  
- 品牌采用鹿溪 CI：产品标与实验室主标双层结构。

## 5. 安装与运行

1. 安装 Python 3.8 或更高版本。  
2. 解压或克隆软件至本地目录 `VectorStream`。  
3. （可选）复制 `.env.example` 为 `.env`，填写 `VS_ADMIN_PIN`。  
4. 在软件根目录执行：`python3 server.py --port 3001`。  
5. 使用浏览器访问 `http://127.0.0.1:3001`。  

仅浏览时也可使用静态文件服务；此时无法进行管理员登录与素材库写回。

## 6. 操作说明（摘要）

详细步骤见《VectorStream 矢量流软件用户使用手册》。

- 浏览：点击分类标签或调整网格密度 / 每页行数。  
- 检索：在顶栏搜索框输入关键词，支持空格分隔的多词组合。  
- 编辑：点击卡片打开预览；点色板行指定取样目标后点击图形取色；使用「按色清除 / 整图换色 / 擦除选块 / 填充选块 / 去掉画板框」。  
- 导出：点击「下载当前 SVG」或「下载当前 PNG」。  
- 管理：顶栏或页脚「管理登录」，输入 `.env` 中配置的口令；登录后预览弹窗出现「写回素材库」。  

## 7. 界面说明

- **主界面**：品牌区、搜索框、视图控件、分类导航、素材网格、分页、出品页脚。  
- **预览编辑弹窗**：棋盘格预览、色板与编辑动作、下载区。  
- **关于 / 管理弹窗**：产品字锁、应用标与实验室主标并列、版权声明、管理登录区。
